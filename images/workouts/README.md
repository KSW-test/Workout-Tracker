# Workout Images & GIFs Directory

Place all your exercise images (`.jpg`, `.jpeg`, `.png`) and animated GIFs (`.gif`) in this folder.

### File Naming Convention
Every image or GIF in this folder must match the exercise name in lowercase with words separated by underscores (`_`):

* **Barbell Bench Press** -> `barbell_bench_press.jpg`
* **Incline Dumbbell Press** -> `incline_dumbbell_press.jpg`
* **Cable Chest Flyes (Animated)** -> `cable_chest_flyes.gif`
* **Conventional Deadlift** -> `conventional_deadlift.jpg`
* **Lat Pulldown (Wide Grip)** -> `lat_pulldown_wide_grip.jpg`
* **Barbell Bicep Curl** -> `barbell_bicep_curl.jpg`
* **Push-Ups** -> `push_ups.gif`
* **Hanging Leg Raises** -> `hanging_leg_raises.gif`

> 💡 **Tip:** You do not need to rename files manually! In the website, when logging a workout or browsing the **Exercise Library**, click **"Select Photo or GIF"** or **"Attach/Rename"**. The website automatically converts the file into the exact standardized name and provides a 1-click download button ready to save into this directory.
