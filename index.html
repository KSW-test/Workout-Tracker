💾 Commit to GitHub Pages

To publish your workouts on GitHub Pages, download the updated data files and commit them to your repository:

git add data/workouts.json data/exercises.json images/workouts/ git commit -m "Log workout" git push origin main
💡 Tip: Place any newly downloaded exercise photos or animated GIFs in your images/workouts/ folder. Once pushed, GitHub Pages will automatically deploy your updates!
